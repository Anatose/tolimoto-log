# Tolimoto Log — заметки для Claude Code

Журнал ТО и заправок для мотоцикла и машины. PWA на React 18 + TypeScript + Vite,
живёт на https://app.tolimoto.com (GitHub Pages, домен через Cloudflare, DNS only).
Издатель — Tolimoto. Владелец общается по-русски; отвечать по-русски.

## Команды

    npm install
    npm run dev        # локальный сервер
    npm test           # расчёты: tsx scripts/test-calc.ts (сейчас 102 ok)
    npm run build      # tsc --noEmit + vite build в dist/

Сквозные тесты (Playwright для Python): собрать с `VITE_GOOGLE_CLIENT_ID=test`,
отдать dist/ на порту 4174, затем `python3 e2e/run_onboarding.py`, `run_google.py`,
`run_renew.py`, `run_ownership.py` (полная стоимость, PDF), `run_archive.py` (архив, удаление), `run_back.py` (системная «Назад», регламент автомобиля). Google в них подменён `e2e/google_mock.py`.
Кнопки искать как `button:has-text("…")`, а не `text=…` (совпадает с текстом абзацев).

Публикация: каждый push в `main` → `.github/workflows/deploy.yml` (тесты, сборка, Pages).

## Устройство

- `src/store.ts` — IndexedDB, настройки (installSeen, onboarded, localAck, lastBackup,
  backupSnooze); `normalize` отмечает онбординг пройденным у тех, у кого уже есть транспорт.
- `src/App.tsx` — порядок первого запуска: выбор языка → InstallIntro (если не установлено
  и !installSeen) → Tour (если !onboarded) → выбор хранения.
- `src/Onboarding.tsx` — установка (iOS: ≡ в адресной строке → «Поделиться» → «На экран
  „Домой“» → «Добавить»), тур, выбор хранения, напоминание о резервной копии раз в 30 дней
  (без Google и при >10 записях), экран «Сохранность данных», navigator.storage.persist.
- `src/google.ts`, `src/sync.ts`, `src/sheetLook.ts` — вход Google и двусторонняя
  синхронизация с таблицей. `src/config.ts`: client ID и scopes (`drive.file email`).
- `src/exportImport.ts`, `src/fuelly.ts` — JSON/CSV, импорт Fuelly и Fuelio.
- `src/i18n.ts` — тексты ru и en; `src/lang/<код>.ts` — uk, et, lv, lt, pl (как на сайте).
  Новые строки — сразу во все 7 (TypeScript не соберётся, если ключа нет). Термины — как в
  инструкции на tolimoto.com. Валюта нового транспорта: pl — zł, uk — ₴, остальные — €.
- `src/sheetLang.ts` — слова Google-таблицы на 7 языках (заголовки, категории, вкладка Summary),
  по шаблонам владельца «Maintenance Tables» на Google Диске. Названия вкладок — только
  английские. Чтение понимает слова любого языка; тест проверяет, что они не пересекаются.
- `src/Owner.tsx` — полная стоимость (Vehicle.ownership: покупка, оценка или продажа; расчёт
  `ownershipCost` в calc.ts), архив (Vehicle.archived: не в карусели, не активный, не в регламенте
  и напоминаниях), сравнение, удаление в два шага. Удалённый транспорт запоминается на устройстве
  (`deleted-vehicles` в kv) до записи в таблицу, чтобы не вернулся из неё.
- `src/Export.tsx` — «История для покупателя»: настоящий PDF прямо на устройстве (window.print()
  в установленном приложении на iPhone не работает). Рисует `src/historyPdf.ts` через jsPDF, который
  грузится только при экспорте; шрифт — урезанный Noto Sans в `public/fonts/` (кириллица, латиница с
  балтийскими и польскими буквами; стрелок и ≈ в нём нет). Шрифты в precache (vite.config.ts), чтобы
  работало без сети; html2canvas, dompurify, canvg заменены пустышкой `src/jspdfStub.ts`. Фото чеков
  скачиваются с Диска (drive.file), если есть вход и сеть, и ужимаются до 1600 px JPEG.
- `src/backNav.ts` — системная «Назад» (Android, браузер): две свои записи в истории (base/top), Back
  закрывает верхнее окно, потом предыдущая вкладка, потом «Гараж»; с «Гаража» — выход (в установленном
  приложении по второму нажатию). После входа в Google с выбором аккаунта страницы Google остаются в истории
  позади приложения — тогда не выходим, а подсказываем закрыть приложение. Вход — `location.replace`.
- Регламент по типу: `PRESETS.moto` / `PRESETS.car`; при смене типа транспорта нетронутые пункты-шаблоны
  переходят на новый тип (`retypeSchedule`), однократный ремонт старых данных — `repairScheduleTypes`.
- `src/Forms.tsx` — настройки; там же строка версии. При релизе менять версию и в
  `package.json`, и APP_VERSION в Forms.tsx (сейчас 0.7.2).

## Правила

- Главный приоритет — чтобы пользователь не потерял данные. Любое изменение хранения,
  синхронизации или импорта проверять тестами и не ломать старые данные (`normalize`).
- Приложение local-first: без своего сервера, без аналитики, без сторонних SDK.
  Это обещано в политике конфиденциальности на tolimoto.com — не нарушать.
- Google: только `drive.file` и `email`. Новый scope = проверка Google и правка политики;
  сначала спросить владельца. OAuth-проект `tolimoto-log` в Google Cloud, статус
  «In production» без проверки; логотип на экран входа не загружать без согласия
  (потребует проверку).
- Рассчитано в первую очередь на iPhone (Safari, установка на экран «Домой»). На экране от 900px
  — раскладка для компьютера (styles.css, конец файла): боковое меню, две колонки, формы окном, Esc.
- Личные данные не коммитить: `data/`, бэкапы, CSV из Fuelly, `scripts/gen-nc750x.mjs`
  в .gitignore. Репозиторий публичный.
- Сначала концепция и согласие владельца, потом код для заметных изменений интерфейса.
- Коммиты: понятные сообщения на английском.

Сайт с инструкцией и политикой — отдельный репозиторий Anatose/tolimoto-site.
